豆包视频工具接口说明

通过 HTTP 接口提交视频任务、查询进度，并管理账号和服务状态。

服务地址请求都以这个地址为前缀
本机：http://127.0.0.1:8787 局域网：http://管理器电脑的IP:8787

网页和管理器在同一台电脑时使用本机地址；从其他电脑访问时使用管理器电脑的局域网地址。请确认管理器已启动并允许 8787 端口通过防火墙。接口当前使用本机授权状态，不需要额外 API Token；浏览器跨域调用请通过同源代理，curl、Postman 或后端调用可直接使用。

快速开始异步提交，立即拿到 requestId
  1. 调用生成接口，提交 prompt 和视频规格。
  2. 记录响应中的 requestId。
  3. 每 1–2 秒调用任务查询接口，直到状态变为 completed 或 failed。
  4. 完成后读取 watermarkFreeUrl 或 watermarkedUrl。
curl -X POST "http://127.0.0.1:8787/api/v1/video/generate" `
  -H "Content-Type: application/json" `
  -d '{"prompt":"海边日落，镜头缓慢向前推进","model":"Seedance 2.0 Mini","ratio":"16:9","duration":10}'
生成视频POST /api/v1/video/generate

默认返回 202，任务在后台执行。需要等待结果时可追加 ?wait=1；建议生产调用使用默认异步方式，避免长连接占用。

字段类型必填说明
promptstring是视频提示词，不能为空。
modelstring否模型名，默认 Seedance 2.0 Mini；也兼容 doubaoModel。
ratiostring否自动、3:4、4:3、9:16、16:9、1:1、21:9。
durationinteger否4–15 秒，默认 10。
filesfile / string[]否multipart/form-data 中重复传入的图片文件或 HTTPS 图片地址；按传入顺序作为参考图。
imageUrlsstring[]否远程参考图，只支持 HTTPS 公网图片地址，单张不超过 20MB。
preferredAccountIdstring否优先使用的账号 ID。
accountLockRequiredboolean否为 true 时必须同时提供账号 ID，失败后不切换账号。
allowPaidQuotaboolean否是否允许使用豆包侧付费额度。
timeoutMsinteger否任务超时参考值；有参考图时服务会自动使用更长的最小超时。
resolutionstring否当前豆包页面没有分辨率控件，只接受空值或 自动；画面尺寸由比例和豆包页面决定。

其他公开接口账号、恢复和诊断
  • GET /health服务健康、授权、队列和账号概览。
  • GET /api/v1/accounts获取账号、登录、套餐状态和本地额度统计。套餐与实际余额分别判断。
  • POST /api/v1/accounts新增账号，可传 {"name":"名称"}。
  • PATCH /api/v1/accounts/{accountId}修改名称或本地额度统计；确认豆包额度恢复后可传 {"resetQuotaExhaustion":true} 允许再次尝试，不增加真实余额。
  • DELETE /api/v1/accounts/{accountId}删除空闲账号。
  • POST /api/v1/accounts/{accountId}/login打开账号的豆包页面并检测登录。
  • POST /api/v1/accounts/{accountId}/check-login重新检测登录和验证状态。
  • POST /api/v1/video/jobs/{requestId}/recheck只核对原会话，不发送消息。
  • POST /api/v1/video/jobs/{requestId}/recover-result仅补取已经提交的原任务；锁定原账号和原会话，不重新发送提示词。
  • POST /api/v1/video/jobs/{requestId}/refresh-url刷新已完成任务的视频地址。
  • POST /api/v1/video/jobs/{requestId}/open-session使用原账号登录环境，只读查看原会话；不导航后台执行页面。
  • POST /api/v1/video/jobs/{requestId}/takeover账号没有自动操作时交接操作权；接管期间暂停该账号调度。
  • POST /api/v1/video/jobs/{requestId}/end-takeover收回页面输入权并核对原任务；发现已有结果后只补取，不发送消息。
  • POST /api/v1/video/jobs/{requestId}/continue-confirmation仅对有未送达依据的普通确认受理一次操作；执行前重新检查原页面，不允许付费时不确认付费。
  • POST /api/v1/diagnostics/browser-rehearsal页面预演：检查多个账号的页面流程，停止在发送前，不生成视频。
  • GET /api/v1/license/status查询授权状态；暂时停用验证时返回 verificationDisabled: true，允许使用工具，不代表已购买授权。
  • POST /api/v1/license/activate提交设备密钥激活授权；暂时停用验证时不请求授权中心、不修改已有密钥。
豆包套餐与额度账号接口中的套餐字段来自最近一次检测

membershipState：standard_member 标准套餐、enhanced_member 加强套餐、premium_member 高级套餐、no_member 普通账号、unknown 待确认。membershipLabel 为套餐名称，membershipSource 为识别来源，membershipCheckedAt 为检测时间。

赠送权益也可能显示套餐标签，不能据此判断是否付费或自动续费。创作额度按免费额度、创作额度包、会员套餐额度依次扣减；会员到期后，未过期的创作额度包余量仍可能可用。套餐级别不能换算成固定视频次数或清晰度，实际权益、余额和恢复时间请查看豆包「订阅与额度管理」。当前接口尚未读取套餐到期日和各类实际余额。

“近7天免费额度已用完”“近30天免费额度已用完”也会暂停账号的免费任务调度。quotaWindowDays 为 7 或 30，quotaRequiresRecheck 为 true；disabledUntil 为 null 表示恢复时间未知，不代表账号可用，请同时检查 disabledReason。这两类限制不会在当天零点自动解除。actualFreeQuotaRemaining 为 0，其他付费额度余额仍未知。

调度与错误处理调用时请按这些规则处理
  • 服务自动从已登录且空闲的账号池调度任务；豆包明确返回额度耗尽时，该账号会暂停调度，避免下一次继续命中。
  • 本地额度统计是辅助信息，最终额度以豆包页面返回为准；不要仅凭本地估算拒绝任务。
  • 收到 429 DOUBAO_QUEUE_FULL 时请退避重试；收到 409 时通常是页面预演或账号状态冲突。
  • 收到 submission_unknown 时先人工核对豆包页面，再调用 resume，避免重复生成。
  • 请求体支持 JSON；带本地图片时使用 multipart/form-data。所有响应均为 UTF-8 JSON。

与最近任务使用同一份记录；不包含未保存的 HTTP 请求耗时。
